Privacy Policy

Cut Tracker and Journal · last updated 22 November 2026

Cut Tracker and Journal is a personal, single-user application. It runs on a private server owned by its only user and is used solely to track that user's own health, fitness and journal entries. It is not offered to the public, has no other users, and is not a commercial product.

What the application accesses

When the user authorises it, the application may read and write:

  • Google Drive — files the user chooses to back up, upload or download through the application.
  • Google Health data — the user's own step counts, sleep, resting heart rate and heart-rate variability, to display them alongside the user's self-entered records.

Access is granted through Google OAuth. The application only ever acts on the account of the person who granted it access.

How data is stored

Data retrieved from Google is stored on the user's own private server, on disk the user controls. It is not copied to any third-party service, analytics platform or cloud account other than the user's own Google Drive.

Sharing

No data is sold, shared, rented or disclosed to any third party. There is no advertising, no analytics and no tracking. The application does not transfer Google user data to any third party, does not use it for advertising, and does not allow humans to read it — there is only one human involved, the user, who owns the data.

Retention and deletion

Data remains on the user's server until the user deletes it. Revoking the application's access at myaccount.google.com/permissions immediately stops any further retrieval. Deleting stored data is a matter of deleting files on the user's own server.

Limited Use disclosure

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
